# スパイクのAPI仕様

## 説明
スパイクモジュールはスパイクを行うドローンを操作するためのモジュールである。
このモジュールを使うことで、ドローンが打つボールの種類を決定することができる。

## 想定利用
サーブ、プレイヤーコントローラ、AIコントローラから呼び出される。

## 公開API

### `void Spike(float course, float velocity)`

コースと速度を指定して、ドローンをボールに当たりに行かせるため。

- `course`の範囲は-1~1で、右端が1, 左端が-1。
- `velocity`は最大速度以下。


### `bool isReady`

ドローンがスパイクの準備を完了しているかどうかを確認するため。

スパイクドローンには、

1. ボールを打ちに行く
1. スパイクするための場所に戻る
1. スパイクをするために待機する

という3つの状態がある. 3の状態のときのみ`isReady = true;`となる

### `float maxVelocity`

ドローンの最大速度。
